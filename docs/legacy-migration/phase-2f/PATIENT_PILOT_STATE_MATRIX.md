# Patient pilot state matrix

## Contract boundary

Version `2F.1.0`. Classic connection `legacy_uhms`, exact database `uuhms`, read-only. The approved local non-production target `uhms_clean` is inspection-only in Phase 2F. This document authorizes no implementation or write and contains no PHI.

Installed metadata, Classic evidence, approved policy and technical recommendation are separate facts. A Classic-evidence cell below contains only a Classic column/fact or the evidenced absence of an approved Classic source field. Database/model defaults describe behavior and are never migration authority. Existing target rows remain byte-for-byte immutable under `PATIENT-TARGET-009` and `PATIENT-TARGET-013`.

## Commit block and dry-run reachability

Commit mode remains blocked until the owner-approved state/timestamp tuple and operational activation/isolation design are recorded and Phase 3 implements them. In dry-run, the unresolved required state is a classified `LEGACY-PATIENT-STATUS-*` patient-and-chain quarantine, not a run failure: Stages 11–23 remain reachable and may produce `BLOCKED_PREREQUISITE`. Invention, mutation, silent default use or an unclassified outcome remains fail-closed.
