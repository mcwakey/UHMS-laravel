# Patient pilot composed column mapping

Status: **Phase 2F technical specification; no importer or persistence is authorized.**

## Boundary and authority

This mapping composes the approved Phase 2A-2E contracts without redefining them. The only Classic source is connection `legacy_uhms`, schema `uuhms`, strictly read-only. The renewed target is the approved non-production environment and remains read-only throughout Phase 2F.

The normative, fully expanded mapping is [`specifications/patient_pilot_composed_column_mappings.json`](specifications/patient_pilot_composed_column_mappings.json), version `2F.1.0`. It contains exactly 33 unique raw source fields and one authoritative owner per field:

| Owner | Field count | Scope |
|---|---:|---|
| Phase 2C | 15 | Patient identity, OPD alias, provenance and extraction-only fields |
| Phase 2D | 7 | Occupation, address, religion, marital status and the three-field NOK tuple |
| Phase 2E | 11 | `patients.Company`, `patients.BillStatus` and all nine `insurance` fields |
| **Total** | **33** | **24 patient fields + 9 insurance fields** |

Phase 2A contributes the resolved provider-crosswalk interface (`NK-004`, `EXTRACT-SETT_PRIVATE`, `RECON-SETT_PRIVATE`), not a second raw Phase 2F extraction. Phase 2B contributes `TARGET-ACTOR-054`, `STAFF-SECURITY-001` and the null-registration-attribution outcome. No staff source field is added.

## Target-owned or unresolved fields

No Classic field owns `patients.patient_number`, `status`, `is_active`, `is_temporary`, `merge_status`, `is_deceased`, `registered_by`, or insurance `member_type`, active/current/primary state, tier, policy number, CCC code, verification, eligibility and timestamps.

- Patient number is target-generated only under `PATIENT-NUM-001..018`; dry-run uses the symbolic nonbinding action `TARGET_GENERATED_AT_COMMIT`.
- Registration attribution is `null` plus protected absence provenance under `TARGET-ACTOR-054` and `PATIENT-ACTOR-003`.
- Patient state and insurance initialization require the explicit Phase 2F matrices. Database/model defaults are not source evidence.
- An unresolved matrix outcome blocks future commit mode; it does not authorize a default or invalidate the mapping specification.

## Global commit blockers

All future units remain blocked until the Phase 3 foundation supplies D-101 source access, environment/schema guards, pinned snapshots, protected remediation/crosswalk/provenance/quarantine/reconciliation stores, HMAC/key management, reviewed patient-number allocation, migration-specific persistence, complete side-effect isolation, idempotency, checkpoints, resume, rollback/compensation and commit-time target collision refresh.

Existing-target patients and their children/memberships remain immutable. Optional child or insurance exceptions never rewrite patient identity. Every insurance source row remains represented in protected history even when no target membership is created.
