# Insurance membership classification

Every source row receives one terminal primary outcome after precedence: extraction/key failure; patient orphan/quarantine; existing-target evidence; provider/type/text/date/member invalidity; group consolidation; selected-current support or historical-only. Diagnostics may overlap but do not double-count.

Required classes include current candidate, historical-only, exact duplicate, conflicting candidates, provider unresolved/ambiguous, blank/duplicate member number, unknown/invalid date, parent quarantined/orphan, existing-target immutable, eligibility not evidenced and extraction failure. Definitions are normative in `insurance_membership_classes.json`.

A class describes migration disposition, never operational eligibility. Every row retains protected history, including duplicates and exceptions.
