# Existing-target insurance contract

The installed target snapshot is read-only evidence. Its nonzero small-cell membership count is suppressed because synthetic/de-identification status is not evidenced; zero duplicate patient/provider groups is safe aggregate evidence. Every pre-existing target membership is immutable. Under Phase 2C, an explicitly linked pre-existing target patient receives no general child enrichment, so Phase 2E creates no membership for that patient even when no target membership currently exists.

A protected, version-matching prior-migration lineage may support an idempotent no-op comparison only after Phase 3 defines it. Without verified lineage, any same patient/provider or member-token collision is a conflict: do not overwrite, clear, reassign, merge, delete or soft-delete. Refresh sanitized collision evidence before each future run. Existing target state never becomes Classic source evidence.
