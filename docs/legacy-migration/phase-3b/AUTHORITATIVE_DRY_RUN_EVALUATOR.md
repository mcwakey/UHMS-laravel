# Authoritative reconciliation and dry-run evaluator

Status: complete foundation evaluator implemented; operational command remains blocked until independently reviewed authoritative recorders and protected-store activation are configured.

`Phase2FMeasurementPlan` derives a closed mandatory registry from the exact 23-artifact bundle: 341 contract assertions and 135 detailed measurements, 476 total. The detailed registry contains 84 acceptance, 47 dry-run and four reconciliation measurements. Each detail retains its contract field kind and must be handled by the fixed adapter registry. Operators cannot choose a subset, add an unknown ID or supply an expected value, difference or tolerance.

Caller-declared `AuthoritativeMeasurement` arrays are rejected unconditionally. `AuthoritativeRecorderSession` captures sealed source/read-only and target-before coordinates, all protected outcome/recovery repository baselines, per-subsystem runtime attempts and a separately sealed target-after coordinate. `RecorderDerivedMeasurementAdapter` contains an explicit closed mapping for all 135 current detail IDs. Source-write facts derive from the verified SELECT/metadata-only source capture, target-write facts from before/after protected set comparison, runtime facts from named subsystem counters, and domain/accounting facts only from a trusted `AuthoritativeAggregateObservationProvider`. Evaluator code computes differences and seals each emitted measurement; providers do not supply verdicts, differences or tolerances.

There is deliberately no production/default aggregate provider. The in-repository `ObservedEmptyCohortAggregateProvider` is limited to synthetic foundation verification: it refuses any source snapshot where the observed patient, child or insurance population is nonzero, binds its zero/N/A observation to all three snapshot IDs, and permits proof that the complete 476-measurement path can emit `DRY_RUN_ACCEPTED_NOT_COMMIT_AUTHORIZED` without inventing domain history. A populated cohort remains blocked until a separately reviewed provider records per-family classification, provenance, quarantine, collision, idempotency, checkpoint, reconciliation, financial, privacy and review observations from the real protected execution sources. Unknown or newly added measurement IDs remain missing rather than falling through to a generic zero.

Missing trusted aggregate evidence produces 135 `blocked_not_measured` details. A nonzero named runtime attempt or target before/after mismatch produces `FAIL_CLOSED`. The accepted synthetic exercise contains all 476 measurements, zero missing and zero failed. All verdicts remain non-commit-authorizing.

The only emitted verdicts are `FAIL_CLOSED`, `BLOCKED_PREREQUISITE`, and `DRY_RUN_ACCEPTED_NOT_COMMIT_AUTHORIZED`. `AggregateDryRunReportBuilder::renderAuthoritative()` validates the closed scalar/stable-ID schema, reports observed source, target and business-domain write counts, and always emits `commit_authorized=false`. The command-level accepted-path test proves the JSON report is still nonbinding.

The `legacy-migration:foundation-reconcile` command composes the evaluator only when the external Phase 2F manifest, explicit evaluator flag and a verified `AuthoritativeRecorderEvidenceProvider` are bound. Otherwise it remains blocked; configuration defaults do not bind either provider and the command accepts no aggregate input file or declared-zero counter. This is foundation infrastructure, not permission to implement an importer, select Cohort B, execute a patient pilot or write a business-domain row.
